Live process table backed by GET /api/processes/watch. CPU percentages are computed in the browser from consecutive tick snapshots. Debug builds generate [process] control = true; release builds keep signals off unless the config enables them.

Try it

  • Filter by pid, user, process name or command line.
  • Click a flat header to sort; click again to reverse.
  • Switch between the compact flat table and the process tree.
  • Expand or collapse branching nodes with the chevron control.
  • Pause and resume the SSE stream.
  • Select a process and send a signal after confirming.

Control

  • Debug builds generate [process] control = true so signals can be tested locally.
  • Release builds keep it off; enable it explicitly and restart to test signals.
  • Only same-user processes, not pid 1, and not the daemon itself.
