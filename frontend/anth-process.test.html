anth-process-monitor

Live process table backed by GET /api/processes/watch. CPU percentages are computed in the browser from consecutive tick snapshots. Signals are disabled unless the daemon config has [process] control = true.

Try it

  • Filter by pid, user, process name or command line.
  • Click any column header to sort; click again to reverse.
  • Switch between the compact flat table and the process tree.
  • Expand or collapse branching nodes with the tree control.
  • Pause and resume the SSE stream.
  • Select a process and send a signal after confirming.

Control

  • Read-only monitoring works with the default config.
  • Add [process] control = true to the config and restart to test signals.
  • Only same-user processes, not pid 1, and not the daemon itself.
