anth-terminal

A reusable xterm.js terminal window. The component only depends on the TerminalTransport interface; this page injects the WebSocket implementation and talks to GET /api/terminal. Start the backend with anth-panel run before connecting.

idle no session

Try it

  • Click Connect, then type in the terminal.
  • Run btop, htop or vim; the window is sized for a full-screen TUI.
  • Run a few commands, then use ↑/↓ to walk the local command history.
  • Resize the browser window; the PTY receives a resize.
  • Use exit to see the exit event and the final code.

Transport-agnostic

  • The component never imports the WebSocket transport.
  • WebSocketTerminalTransport implements the same interface a mock or native bridge would.
  • The generic JsonWebSocketTransport can be reused by other endpoints.
