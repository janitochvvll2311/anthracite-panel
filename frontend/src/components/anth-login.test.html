The sign-in screen shown when the auth cookies are gone. The harness accepts the user admin with the password hunter2 and rejects everything else with the same message the daemon sends.

Try it

  • Submit with a wrong password: the error comes from the server.
  • Submit with hunter2: the field clears and the event fires.
  • Press Enter instead of clicking: the form still submits.
  • The password is never stored; it is cleared on both paths.

Session shape

On success the component reports the session it read back from GET /api/auth/session. The shell, not this component, decides what to render next.
