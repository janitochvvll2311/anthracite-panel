The panel configuration, read from GET /api/config and written through PATCH /api/config. This harness runs against an in-memory copy, so nothing here touches the real config file.

Try it

  • Toggle a control and press Save: the patch panel shows the diff.
  • Press Save again with no change: the form answers "Nothing changed." and sends nothing.
  • Set the files root to a relative path and press Save: the fake server rejects it and the error is shown, with the draft intact.
  • The password has no field: it changes through anth-panel auth set-password or POST /api/auth/password, which checks the current one.

Why a patch, not a full save

A full replacement would overwrite a field another tab changed while this form was open. The component diffs the draft against the loaded view and sends only the sections that differ.
