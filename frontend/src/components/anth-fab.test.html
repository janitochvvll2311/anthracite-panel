A 56px action button owned by one panel. It is visible in portrait and hidden in landscape unless mobile-only is cleared. Only the active panel's FAB exists, because hidden tabs are detached.

Try it

  • The button sits fixed at the bottom-right of the viewport.
  • Toggle Disabled to see the unavailable state.
  • Toggle Allow in landscape to opt out of the mobile-only rule.
  • Click it; the last click is printed below.

Run it

  • bun run dev from frontend/.
  • Open /src/components/anth-fab.test.html on the Vite port.
  • Change the viewport orientation to compare portrait and landscape.
