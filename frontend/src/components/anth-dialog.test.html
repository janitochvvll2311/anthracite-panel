The modal frame and the promise-based dialogs that replace window.confirm, window.prompt and window.alert. Open a question to see the queue: a second request waits until the first is answered.

Try it

  • Confirm and cancel a question, then close with Escape.
  • Click the backdrop; it means cancel.
  • Submit an empty prompt to see validation hold it open.
  • Fire two questions at once to watch the queue.
  • Press Tab inside a modal: focus stays within it.
  • Answer a question: focus returns to the button that opened it.

How a component uses it

if (!(await confirmAction({
  title: 'Stop the daemon?',
  danger: true,
}))) return
