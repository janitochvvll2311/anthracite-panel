One theme and the tab strip of its panels. The shell caches one of these per theme; the hidden tabs are detached by anth-tab-panel, so switching back resumes where it left off instead of keeping a second stream open.

Try it

  • Switch themes and panels to see the tab strip change.
  • Notice that a hidden tab is removed from the DOM, not merely hidden.
  • Open the browser inspector and check that a cached page keeps its element while another theme is shown.

Run it

  • cargo run -p anth-panel -- run from backend/.
  • bun run dev from frontend/.
  • Open /src/components/anth-theme-page.test.html on the Vite port.
