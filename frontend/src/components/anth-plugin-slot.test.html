The shell renders one of these wherever a plugin may appear. It asks the loader for the elements declared for its slot, imports each module and appends the declared tag. Nothing here imports a plugin statically.

Try it

  • Good plugin registers anth-widget and appears in the slot below.
  • Broken plugin throws on import. It is skipped and logged; the good one still mounts.
  • Disabled plugin is not loaded at all, because the asset route would refuse it.

Why the slot and not the shell

Keeping the loader behind an element means the shell contains no plugin tag and no plugin import. A plugin is data — an id, a slot, a tag, a module — until this element runs.
