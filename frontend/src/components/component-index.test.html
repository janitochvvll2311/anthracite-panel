Every dev-only component harness in one place. Open a page, exercise it against a local daemon, and use the back button or this index to move between components.

Run the stack

  • cargo run -p anth-panel -- run from backend/.
  • npm run dev from frontend/.
  • Open this page at /src/components/component-index.test.html.

Production

These pages are not build entries. Vite's only production input is index.html, so nothing here is embedded in the panel.
