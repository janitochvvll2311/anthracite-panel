CodeMirror-backed text editor used by the file explorer preview. It shows line numbers, syntax highlighting for the grammars the panel ships, and word autocompletion. Saving goes through POST /api/files/write with the mtime the file was loaded at, so a concurrent change is refused instead of overwritten.

Try it

  • Pick one of the sample files; each exercises a different grammar.
  • Type to mark the buffer dirty and press Save to write it back.
  • Save with Stale precondition ticked to see the conflict path: the daemon refuses and the buffer stays dirty.
  • Untick writes to see the read-only state.

Run it

  • cargo run -p anth-panel -- run from backend/.
  • npm run dev from frontend/.
  • Open /src/components/anth-file-editor.test.html.
