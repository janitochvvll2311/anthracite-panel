Local users and groups backed by GET /api/accounts. It lists users and groups in two tables, creates and edits them, locks an account and sets a password. Refresh is manual: there is no watch stream. Mutations are disabled unless [accounts] control is enabled, and the password form needs manage_passwords as well.

Try it

  • Filter by name, id, comment or group member.
  • Switch between the Users and Groups tabs.
  • Sort either table by clicking a header.
  • Look for a greyed row: nss accounts, uid 0, system accounts and privileged groups explain why they are locked.
  • Try a name with a slash or a system account to see the daemon's refusal.

Run it

  • cargo run -p anth-panel -- run from backend/.
  • npm run dev from frontend/.
  • Open /src/components/anth-account-manager.test.html on the Vite port.
  • Debug builds enable [accounts] control and leave manage_passwords off, so the password action stays hidden until you turn it on.
  • The daemon needs root, or a NOPASSWD sudoers rule, to write the account files.
