Tabs that keep a hidden tab's state without keeping its DOM. Each tab below reports when it connects and disconnects: switch away and its counter stops, which is the saving this component exists for. The selection is remembered under storage-key.

Try it

  • Switch tabs: the counter of the tab you left freezes, because it was detached. Come back and it resumes with a new connect.
  • Toggle the disabled tab: it becomes selectable, then blocked again.
  • Type in a field, leave the tab and come back: the value stays.
  • Use the arrow keys, Home and End on the strip.
  • Reload the page: the last tab is still selected.
  • Add a tab with the button; the strip rebuilds without losing the active one.

Streams and parking

A monitor inside a tab stops its SSE stream when the panel parks it and starts it again on the anth-tab-show event the panel dispatches when it puts the tab back. A paused monitor stays paused.
