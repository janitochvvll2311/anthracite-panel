Host overview backed by GET /api/host-info and its /watch SSE endpoint. It shows the operating system, kernel, architecture, CPU, load average, memory and swap. Pause the stream to keep the last snapshot visible while the daemon is stopped.

Try it

  • Change the interval to restart the SSE stream.
  • Pause and resume the live feed.
  • Refresh once without restarting the stream.
  • Stop the backend to see the stream error state.

Run it

  • cargo run -p anth-panel -- run from backend/.
  • npm run dev from frontend/.
  • Open /src/components/anth-host-info.test.html on the Vite port.
