Storage inventory backed by GET /api/volumes. It lists block devices as a tree and every mount as a table, mounts an unmounted device on an existing directory and unmounts a real mount. Refresh is manual: there is no watch stream. Writes are disabled unless [volumes] control is enabled.

Try it

  • Filter by device, label, filesystem or mountpoint.
  • Sort the device and mount tables by clicking a header.
  • Mount an unmounted partition on a directory below volumes.mount_root.
  • Unmount a non-virtual mount after confirming.
  • Try a target outside the mount root, or a virtual filesystem, to see the daemon's refusal.

Run it

  • cargo run -p anth-panel -- run from backend/.
  • npm run dev from frontend/.
  • Open /src/components/anth-volume-manager.test.html on the Vite port.
  • Debug builds enable [volumes] control with mount_root = "/mnt".
