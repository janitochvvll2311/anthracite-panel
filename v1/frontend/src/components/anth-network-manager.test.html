Live network-interface monitor backed by GET /api/network and its /watch SSE endpoint. It shows state, addresses, link speed, cumulative traffic and per-second rates. When [network] control is enabled, each row also offers an up/down action.

Try it

  • Change the interval to restart the SSE stream.
  • Pause and resume the live feed.
  • Select a row to inspect MAC, MTU, duplex and counters.
  • Sort by state, speed, rates or totals.
  • Filter by interface name, address, MAC or state.
  • With network control enabled, bring an interface up or down. Bringing lo down is refused by the daemon.
  • With [network] manage enabled, create a virtual interface, edit its MTU, rename it while it is down, or delete it. Deleting a physical device warns first; the daemon still refuses to delete the interface the request arrived on and the last default-route carrier.

Run it

  • cargo run -p anth-panel -- run from backend/.
  • bun run dev from frontend/.
  • Open /src/components/anth-network-manager.test.html on the Vite port.
  • Debug builds enable [network] control and [network] manage; release builds keep both off.
