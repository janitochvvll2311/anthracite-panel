Installed plugin bundles from GET /api/plugins, their frozen capabilities and the browser install path. Installation posts the zip to POST /api/plugins/install and is disabled unless [plugins] install_from_web is on. A signature is required unless [plugins] require_signature = false, in which case the install reports that it was not verified.

Try it

  • Open the panel from the shell or this harness.
  • Choose a bundle and confirm the warning: the file is uploaded and the catalogue refreshes.
  • Set install_from_web = false to see the read-only state.
  • Install an unsigned bundle with require_signature = false to see the warning.
  • Break a granted module to see the problems list.

Run it

  • cargo run -p anth-panel -- run from backend/.
  • bun run dev from frontend/.
  • Open /src/components/anth-plugin-manager.test.html on the Vite port.
  • Debug builds enable [plugins] enabled and install_from_web in the generated config.
