A native <dialog> sliding in from the left. The platform supplies the top layer, focus trap, Escape handling and focus restoration. The shell owns open and closes the drawer in response to anth-drawer-close.

Try it

  • Use a portrait viewport; landscape intentionally hides it.
  • Open the drawer, then press Escape or click the backdrop.
  • Click a link; the drawer reports the reason and closes.
  • Check that focus returns to the trigger after closing.

Run it

  • bun run dev from frontend/.
  • Open /src/components/anth-nav-drawer.test.html on the Vite port.
