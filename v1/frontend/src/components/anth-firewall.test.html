Managed nftables firewall backed by GET /api/firewall. It reads the dedicated inet anthracite table, adds deny rules, removes managed denies with allow, deletes rules by handle and flushes the chain. Changes are disabled unless [firewall] control is enabled.

Try it

  • Add an allow or deny rule for a port.
  • Delete a rule by its handle after confirming.
  • Flush the managed chain.
  • Expand the nft ruleset to inspect the raw output.
  • Disable [firewall] control to see the read-only state.

Run it

  • cargo run -p anth-panel -- run from backend/.
  • npm run dev from frontend/.
  • Open /src/components/anth-firewall.test.html on the Vite port.
  • The daemon needs nft and CAP_NET_ADMIN. Debug builds enable [firewall] control.
