Filesystem manager backed by GET /api/files. It shows breadcrumbs, sorting, hidden files, archives, a text editor, text/image previews and the write controls. The listing scrolls inside a bounded height so the preview stays visible. Debug builds generate [files] write = true; in release, enable it explicitly before testing uploads, renaming or deletion.

Try it

  • Navigate with the breadcrumbs or by double-clicking a folder.
  • Click a header to sort; directories stay first.
  • Toggle hidden files and preview text, images or binaries.
  • With writes enabled, create, upload, rename and delete.
  • Select a text file and press Edit to open it in anth-file-editor.

Run it

  • cargo run -p anth-panel -- run from backend/.
  • npm run dev from frontend/.
  • Open /src/components/anth-file-manager.test.html on the Vite port.
