# The acid test

`app/` is a complete app that lives **outside** `apps/` and outside the apps
workspace: its own `[workspace]`, its own lockfile, and nothing from this
repository except the `anth-guest` SDK. `scripts/acid-test.sh` builds it with
plain `cargo`, packs and signs it with `anth-sign`, and proves that a real panel
installs, composes, serves and answers it with no engine change (§1, §11).

The bundle is signed by a key generated for the run and trusted through the
keyring, exactly as a third party would do; the panel starts with
`require-signature = true`, so an unsigned or untrusted bundle cannot pass.
`tests/acid/app/wit/deps/` is generated by the app's build script and ignored.
