# @anth-panel/client

Generated by `scripts/codegen.ts` from `apps/hello`; do not edit the generated
sources by hand.

## Layers

- `src/http.ts` — the typed HTTP/route client (`GreetingHttpClient`). It builds
  the route path, query/body and parses the JSON result.
- `src/cli.ts` — the CLI client (`run(transport, verb, args)`). It parses flags
  and delegates to the HTTP client; it does not own a socket or a fetch.
- `src/transport.ts` — `Transport`, an HTTP request adapter
  `(method, path, body) => Promise<string>`.
- `src/commands.ts` — the generated command table (verb, method, path, params).

## Transport

The client never knows whether the engine is reached over a Unix socket or TCP.
An adapter implements `Transport`:

- a **UDS** adapter speaks HTTP over the Unix socket;
- an **HTTP/TCP** adapter can use `fetch` or a direct TCP client;
- tests use a fake transport.

The CLI client and the HTTP client share the same injected transport.
