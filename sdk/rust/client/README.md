# anth-client

Generated by `scripts/codegen.ts` from `apps/hello`; do not edit the generated
sources by hand.

## Layers

- `src/http.rs` — the typed HTTP/route client (`GreetingHttpClient`). It builds
  the route path, query/body and parses the JSON result.
- `src/cli.rs` — the CLI client (`run(transport, verb, args)`). It parses flags
  and delegates to the HTTP client; it does not own a socket.
- `src/lib.rs` — `Transport`, an HTTP request adapter:
  `request(method, path, body) -> Result<String, ClientError>`.
- `src/commands.rs` — the generated command table.

## Transport

The client never knows whether the engine is reached over a Unix socket or TCP.
An adapter implements `Transport`:

- a **UDS** adapter speaks HTTP over the Unix socket;
- an **HTTP/TCP** adapter can use a TCP client;
- tests use a fake transport.

The CLI client and the HTTP client share the same injected transport.
